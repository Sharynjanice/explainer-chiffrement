La démarche

Problème. Le chiffrement de bout en bout est abstrait pour un avocat, alors que c’est sa garantie de confidentialité.

Choix de design. Une seule idée par écran, aucun jargon, et un point de vue « serveur » pour rendre l’invisible visible.

Réalisation. Le chiffrement affiché est réel (AES-256 via la Web Crypto API du navigateur), pas une simulation.

Outils. Figma pour les maquettes, HTML, CSS et JavaScript pour le prototype, Vercel pour la mise en ligne.
